🆘 TROUBLESHOOTING

Problem: "Build Failed"
  Solution: Check Railway logs for specific error
           Ensure Dockerfile is in root directory
           Verify all dependencies in requirements-prod.txt

Problem: "Connection Refused"
  Solution: Wait a few more minutes (first build is slow)
           Check Railway deployment status
           Verify no errors in logs

Problem: "Audio Not Generating"
  Solution: Check that edge-tts is installed
           Verify text input is not empty
           Check server logs for errors

Problem: "Can't Find Files"
  Solution: Ensure files are committed to Git
           Check .gitignore doesn't exclude them
           Verify folder structure matches app.py
